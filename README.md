# marutyan/.github

このリポジトリは GitHub の org-wide default community health files として、
`marutyan` 配下の全リポジトリに既定の issue / PR テンプレートを提供する。

テンプレートの内容・運用ルールの SSoT は `~/.claude/rules/06-github-flow.md`。
規約を変更する場合は先にそちらを更新し、本リポジトリのテンプレートを追従させること。

GitHub の仕様上、default community health files は public リポジトリでのみ
組織全体に適用されるため、本リポジトリは public で公開する必要がある。
