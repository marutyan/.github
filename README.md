# marutyan/.github

`marutyan`配下のリポジトリへ、既定のIssue・プルリクエストテンプレートを提供する。

## 適用

- 対象リポジトリに対応する固有テンプレートがある場合は、そちらを使う。
- 対応する固有テンプレートがない場合は、このリポジトリのテンプレートを使う。
- 対象リポジトリにIssue Template、Issue Form、またはその設定がある場合、このリポジトリのIssueテンプレート群は使われない。

## 方針

- Issueは、bugや意図しない状態を記録するために使う。やること一覧には使わない。
- 一つのIssueには一つの問題だけを書く。
- 一つのプルリクエストには一つのテーマだけを書く。
- 本当に重要な内容を、日本語で簡潔かつ分かりやすく書く。
- ラベルは必須にしない。

このリポジトリはテンプレートだけを管理する。Issueやプルリクエストを作る条件、branch、commit、mergeなどの操作手順は各ハーネス側で定める。

## 注意

既定テンプレートを利用するため、このリポジトリはpublicで維持する。秘密情報、認証情報、privateな環境情報を含めない。
